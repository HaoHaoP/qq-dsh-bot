# qq-dsh-bot

把 QQ 个人号接进 DeepSeek Harness 的一套配置与自研插件。

协议端用 SnowLuma，智能体用 dsh，通道用 OneBot v11。自研插件以 AGPL-3.0 开源。

## 目录

| 路径 | 内容 |
| --- | --- |
| docs/requirements.md | 需求文档，范围、方案对比、验收 |
| docs/persona.md | 人格文本与命名来历 |
| plugins/quota-gate | 按群与按人的日 token 预算闸门，待实现 |
